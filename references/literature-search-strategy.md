# 文献检索策略手册（Literature Search Strategy）

> 子技能 `literature-review` 给了"搜索策略模板"和 PRISMA 流程，但没回答**数据库怎么选、布尔式怎么搭、什么时候该停、重复文献怎么去**。本篇把检索从"随便搜搜"变成可复现、可审计的策略。

## 1. 数据库选型矩阵

| 研究方向 | 首选库 | 补充库 | 理由 |
|----------|--------|--------|------|
| 医学/生物 | PubMed / MEDLINE | Cochrane, Web of Science | 学科权威、循证强 |
| 综合/理工 | Web of Science / Scopus | Google Scholar | 引文网络全 |
| 计算机 | DBLP / arXiv / ACM DL | Google Scholar | 预印本快、覆盖全 |
| 社科 | Scopus / SSRN | Google Scholar | 工作论文多 |

> 不要只用一个库——单一库漏检率高。至少 2 个互补库交叉。

## 2. 布尔式搭建（PICO 驱动）

用 PICO 把研究问题拆成维度，再映射布尔：

```
P (Population)  →  (adolescent OR teenager OR "young adult")
I (Intervention)→  AND (CBT OR "cognitive behavioral")
C (Comparison)  →  AND (medication OR "treatment as usual")
O (Outcome)     →  AND (relapse OR remission)
```

规则：
- OR 用于同义/近义扩展，用括号分组：`(A OR B)`
- AND 用于维度连接
- NOT 慎用——会误删相关文献（如排除 "children" 可能漏掉 "adolescents"）
- 短语用引号 `"cognitive behavioral"` 避免词序错位

## 3. 滚雪球（Snowballing）

检索饱和后做两层滚雪球：
- **向后滚雪球**：读入选文献的参考文献列表，找被引的关键文献
- **向前滚雪球**：用引文追踪（Google Scholar "被引用"）找后续引用文献

停止条件：连续两轮滚雪球无新增高相关文献 → 检索饱和。

## 4. 去重决策

同文献可能以不同元数据出现在多库。判定重复：
- 强信号：DOI 相同 → 必重
- 中信号：作者+标题归一化相同 → 必重
- 弱信号：仅年份/卷期不同 → 人工核对

去重在导入文献管理工具（Zotero/EndNote）后做，或用脚本（见 `reference-management-playbook.md` 的重复检测）。

## 5. 可执行的检索辅助命令

```bash
# 导出检索结果后统计各库命中数（评估覆盖）
for db in pubmed scopus; do echo "$db: $(wc -l < $db.ris)"; done

# 用本仓库脚本检测 .bib 中的重复条目
python3 scripts/check_references.py bibtex --file refs.bib
```

## 6. 典型坑与规避

| 坑 | 表现 | 规避 |
|----|------|------|
| 只用 Google Scholar | 漏检、重复多 | ≥2 互补库交叉 |
| 滥用 NOT | 误删相关文献 | 仅在明确排除时用 |
| 布尔不分括号 | 逻辑错乱 | 每个 OR 组加括号 |
| 不滚雪球 | 关键文献缺失 | 饱和后向后+向前滚 |
| 检索无时间窗 | 噪声大 | 设合理年限（如 2018-2026） |
| 重复文献混入选集 | 综述虚胖 | 导入后去重 |

## 7. 检索记录模板

每次检索记录以下字段，保证可复现、可审计：

```
日期: 2026-08-08
数据库: PubMed + Scopus
检索式: (adolescent OR "young adult") AND (CBT OR "cognitive behavioral") AND relapse
年限: 2018-2026  语言: English  类型: peer-reviewed
命中: PubMed 312 / Scopus 408 / 去重后 540
排除: 动物实验 40 / 非英文 22
```

> 审稿人常要求"检索方法可复现"，这份记录直接进综述的 Methods 段。

## 8. PRISMA 与文献管理

- **PRISMA 流程图**：识别(n) → 排除(重复/标题摘要/全文) → 纳入(final)，每个数都记。
- **文献管理工具**：Zotero/EndNote 导入各库 RIS，自动去重，导出 BibTeX 供 LaTeX 用。
- **雪球边界**：向后（参考文献）+ 向前（被引）各做一轮，记录新增与饱和判定。

## 9. 实战：Transformer 模型压缩综述的检索

目标：写一份"Transformer 模型压缩"系统性综述。

```
数据库: DBLP + arXiv + Web of Science
PICO:
  P = 预训练/微调后的 Transformer
  I = 剪枝/量化/蒸馏/稀疏化
  C = 全参数基线
  O = 精度保持率、推理加速比
布尔:
  ("model compression" OR pruning OR quantization OR distillation)
  AND ("transformer" OR "BERT" OR "ViT")
  AND (accuracy OR "inference speed")
年限: 2019-2026  语言: English  类型: peer-reviewed
命中: 612 → 去重 540 → 标题摘要筛 180 → 全文 95 → 纳入 62
雪球: 向后 40 + 向前 28，新增 12，达饱和
```
产出：检索记录（Methods 段用）+ PRISMA 流程图 + 62 篇去重后的 BibTeX（过 `check_references.py`）。

## 10. 检索反模式（扩展）

| 反模式 | 后果 | 修正 |
|--------|------|------|
| 只用 1 个库 | 漏检 | ≥2 互补库 |
| 滥用 NOT | 误删相关 | 谨慎用 |
| 不滚雪球 | 缺关键文献 | 饱和后双向滚 |
| 无时间窗 | 噪声大 | 设年限 |
| 不记检索式 | 不可复现 | 写检索记录 |
| 重复文献混入 | 综述虚胖 | 导入去重 |
| 同义不扩展 | 漏检 | OR 扩同义 |
| 仅看摘要 | 误纳 | 全文精筛 |
| 不查 DOI | 不可核验 | 补全 doi |
| 停太早 | 不全 | 连续两轮无新增才停 |

## 11. 检索质量自评

| 维度 | 达标信号 |
|------|----------|
| 覆盖度 | ≥2 互补库 + 滚雪球饱和 |
| 可复现 | 检索记录完整、检索式可重跑 |
| 去重 | 导入工具去重 + 脚本查重 |
| 相关 | 纳入文献 80%+ 紧扣 PICO |
| 时效 | 近 5–8 年占比合理，旧经典单列 |

任一不达标 → 补做对应步骤再写综述 Methods。

## 13. 检索结果的筛选与沉淀

命中几百篇后，如何高效筛到真正要读的，并沉淀成可写进综述的素材：

- **两级筛选**：先读标题/摘要排除明显不相关（占比常 60-70%），再全文精读留 20-30%。不要一上来通读全文，既慢又浪费。
- **筛选标准先行**：写清纳入/排除标准（如"仅 peer-reviewed、仅 2018 后、仅英文"），避免标准随文献漂移导致前后不可比。
- **文献笔记模板**：每篇读后记三行，日后写 Related Work 直接拼：
  ```
  文献: Smith 2020 (JMLR)
  问题: 大模型剪枝后如何保精度
  方法: 结构化剪枝 + 知识蒸馏
  与本文关系: 是 S1 的基线，本文在其上加速 2.3×
  ```
- **证据分级**：RCT/元分析 > 队列研究 > 案例研究；写综述时高等级证据放前面撑论点，低等级作补充。
- **追踪被引**：入选文献里高被引的几篇，用"被引用"向前滚，找最新进展，避免综述一写就过时。
- **综述地图**：把纳入文献按主题聚类画成地图，找"空白区"——那往往就是你的贡献点。

## 14. 检索常见误判与修正（扩展）

| 误判 | 后果 | 修正 |
|------|------|------|
| 命中多=检索好 | 噪声大、筛到崩 | 看精准率非召回率 |
| 只看摘要纳入 | 误纳不相关 | 全文精筛 |
| 标准中途改 | 前后不可比 | 标准先行写死 |
| 不记笔记 | 写时忘了出处 | 读后即记三行 |
| 忽略被引追踪 | 综述过时 | 高被引向前滚 |
| 混用库导出格式 | 去重错乱 | 统一 RIS/BibTeX 导出 |
| 不查 DOI | 不可核验 | 补全 doi |
| 停太早 | 覆盖不全 | 连续两轮无新增才停 |
