# 论文章节组装检查清单手册（Manuscript Assembly Checklist）

> 子技能 `paper-assembly` 给了"IMRaD 结构、论证链、段落衔接"，但没把**每章该过哪些硬检查、论证链怎么逐条验证、全文一致性怎么扫**量化成可勾选清单。本篇把组装从"写完就行"变成可审计的验收单。

## 1. IMRaD 验收矩阵

| 章节 | 必过检查 | 失败信号 |
|------|----------|----------|
| Introduction | 痛点→空白→贡献三段清晰；贡献点可数（3 条左右） | 贡献写成"本文研究了…"（无具体增量） |
| Methods | 可复现：数据/参数/环境齐全；伦理声明（如适用） | 别人按写无法复现 |
| Results | 只报发现不解释；图表编号与正文引用对应 | 结果与讨论混写 |
| Discussion | 回答引言问题；关联已有工作；讲局限性 | 重复结果、无局限 |
| Conclusion | 一句话核心贡献 + 未来方向 | 又展开新结果 |

## 2. 论证链验证（逐条）

每条主张必须有：`主张 → 证据 → 推理` 三件套。逐段扫描：

```
for 每段:
  提取主题句（主张）
  是否存在支撑证据（数据/引用/实验）？
  推理是否显式连接主张与证据？
  无证据的主张 → 标记 [unsupported]
```

> 反模式：满是"显然""众所周知"却无引用的主张——审稿人最反感。

## 3. 全文一致性扫描

| 维度 | 检查 | 工具 |
|------|------|------|
| 术语 | 同一概念全篇同名 | 人工 / grep 候选异名 |
| 时态 | 已完成用过去时，普遍结论用现在时 | 人工 |
| 图表引用 | 每图每表被正文引用且编号连续 | grep `Figure/Table \d` |
| 缩写 | 首次出现写全称 | 人工 |
| 文献 | 正文 `\cite` 全部在 .bib | 见 `reference-management-playbook.md` |

## 4. 可执行的辅助命令

```bash
# 检查 Figure/Table 引用是否连续且无遗漏
grep -oE 'Figure [0-9]+|Table [0-9]+' manuscript.tex | sort -u

# 检查未定义的 \cite 键（需配合 .bib）
# 见 academic-citation 子技能的交叉比对流程
```

## 5. 典型坑与规避

| 坑 | 表现 | 规避 |
|----|------|------|
| 贡献不具体 | "本文研究了X" | 写清 3 条增量 |
| 主张无证据 | "显然…" | 每条主张配证据 |
| 结果混讨论 | 结果里解释意义 | 结果只报，讨论再解 |
| 图表漏引用 | 图存在但正文没提 | 每图每表被引用 |
| 术语漂移 | 同物异名 | 全文统一术语 |
| 时态乱 | 过去/现在混 | 已完成过去时、普适现在时 |

## 6. 组装检查清单

- [ ] Introduction：痛点→空白→可数贡献
- [ ] Methods：可复现，参数/数据/环境齐全
- [ ] Results：只报发现，图表编号与正文对应
- [ ] Discussion：回扣引言、关联文献、含局限性
- [ ] Conclusion：一句话贡献 + 未来方向
- [ ] 每条主张有证据与推理（无 [unsupported]）
- [ ] 术语/时态/缩写全文一致
- [ ] 所有 `\cite` 在 .bib 中有对应且字段完整
